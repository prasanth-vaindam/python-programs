What is the bytes Data Type in Python?
bytes is a data type used to store binary data (data represented as bytes).

A byte can hold a value from 0 to 255.
bytes objects are immutable (cannot be changed after creation).

----------------------------
What is bytearray in Python?

A bytearray is like bytes, but it is mutable (you can change its contents).

Stores values from 0 to 255.
Used for binary data.
Can be modified after creation.
-------------------------------
We use memoryview when working with large binary data because it lets us
access the data without creating a copy.
This saves memory and makes programs faster.
